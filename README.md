# HEXAGON Search

Это веб-приложение: страница сайта и сервер поиска должны работать вместе.

## Почему при открытии HTML с телефона появляется Failed to fetch

Если открыть `index.html` прямо из загрузок Android, адрес начинается с `content://...`. Это просто просмотр локального файла. Серверный адрес `/api/search` в таком режиме не существует, поэтому поиск не может получить результаты.

## Публикация в интернете через Render

1. Распакуйте ZIP на компьютере.
2. Создайте репозиторий на GitHub и загрузите в него все файлы из папки `hexagon-search`.
3. На Render выберите **New → Blueprint** и подключите этот GitHub-репозиторий.
4. Render найдёт `render.yaml` и создаст веб-сервис. Дождитесь статуса **Live**.
5. Откройте выданный Render адрес вида `https://имя-сервиса.onrender.com`.

После публикации открывайте именно адрес Render, а не локальный `index.html`.

## Запуск на компьютере без публикации

Нужен Node.js 18 или новее. В папке проекта выполните `npm start`, затем откройте `http://localhost:3000`.

## Как устроен поиск

Страница обращается к серверу HEXAGON по `/api/search`. Сервер получает JSON-результаты от совместимого SearXNG-инстанса и возвращает их на страницу. Переход на сайт-источник происходит только при нажатии на результат.

Публичные SearXNG-инстансы могут временно не отвечать или ограничивать запросы. Для стабильной работы настройте собственный SearXNG и переменную окружения `SEARXNG_URL`, указывающую на него. В SearXNG должен быть включён JSON-формат.

## Ограничения

Это поисковый агрегатор, а не собственный поисковый робот: он не строит отдельный индекс интернета. Доступность и полнота результатов зависят от поисковых источников.
