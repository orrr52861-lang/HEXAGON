# HEXAGON Search

Поисковый сайт, который собирает короткие фрагменты информации из найденных страниц и показывает их в одном ответе на сайте HEXAGON.

## Запуск
- Требуется Node.js 18 или новее.
- `npm start`
- Откройте `http://localhost:3000`.

## Развёртывание на Render
Проект рассчитан на Render Web Service. Build command: `npm install`, Start command: `npm start`.

## Как устроен поиск
1. Сервер получает результаты поиска DuckDuckGo.
2. Пытается прочитать до шести найденных HTML-страниц.
3. Извлекает текст и выбирает короткие предложения, связанные с запросом.
4. Показывает собранную информацию и список источников на HEXAGON.

Это не ИИ-генерация и не проверка истинности фактов: это автоматический сбор и отбор фрагментов. Некоторые сайты блокируют автоматическое чтение, а поисковый источник может ограничивать частые запросы. В таком случае будут показаны доступные поисковые описания либо сообщение об ошибке.
